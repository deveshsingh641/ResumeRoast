=== SLIDE 3 ===
  [Text]: Background / Existing Approach
  [Text]: Traditional Architecture Deficiencies vs. Modern Engineering Requirements
  [Text]: Traditional / Existing Web Store Deficiencies
  [Text]: • Monolithic Architecture: Tight coupling forces full-page reloads for catalog and cart changes.
  [Text]: • Volatile Session State: Cart items frequently vanish upon session timeout or browser refresh.
  [Text]: • Flat Authorization: No strict role separation between public shoppers and store administrators.
  [Text]: • Direct Table Queries: Direct scans across unindexed schemas cause high latency bottlenecks.
  [Text]: • Manual Local Hosting: Fragile manual deployments without modern automated cloud CI/CD pipelines.
  [Text]: Modern MERN Architecture Requirements (Our Solution)
  [Text]: • Decoupled SPA Frontend: React 18 & Vite provide instant, reactive interactions with zero page reloads.
  [Text]: • Persistent Context Hydration: CartContext + LocalStorage preserves shopping state across all visits.
  [Text]: • Role-Based Security: Strict JWT authentication and middleware isolate admin routes completely.
  [Text]: • Optimized Mongoose Schemas: Indexed MongoDB models and embedded sub-documents ensure fast queries.
  [Text]: • Production Cloud Delivery: Automated cloud deployment with environment configuration and monitoring.
  [Text]: Architectural Paradigm Shift:
  [Text]: Transitioning from rigid server-rendered monoliths to an API-first, role-protected MERN platform delivering high-speed interactivity, persistent client state, and scalable cloud deployment.

  [Text]: 1. Cart State Synchronization
  [Text]: Frontend State Persistence
  [Text]: • Challenge: Shopping cart state lost after browser page reload and tab switches.

  [Text]: • Impact: Seamless zero-reload cart retention with optimistic UI updates.
  [Text]: 2. Role-Based Access Control
  [Text]: Backend Route Security
  [Text]: • Challenge: Administrative product CRUD and analytics exposed to public routes.
  [Text]: • Solution: JWT authentication middleware verifying role claims ('admin' vs 'user').
  [Text]: • Impact: 100% guarded admin endpoints with zero privilege escalation.
  [Text]: 3. Order Lifecycle Tracking
  [Text]: Mongoose Database Modeling
  [Text]: • Challenge: Tracking multi-stage fulfillment without heavy relational database joins.
  [Text]: • Solution: Embedded timelineStepSchema sub-documents directly within Order model.
  [Text]: • Impact: O(1) milestone retrieval for real-time buyer order status updates.
  [Text]: 4. Dynamic Search & Responsive UI
  [Text]: Catalog & Tailwind Architecture
  [Text]: • Challenge: Sluggish concurrent keyword and category filtering across mobile viewports.
  [Text]: • Solution: Indexed MongoDB queries with debounced regex matching & Tailwind flex layouts.
  [Text]: • Impact: Sub-45ms search response time with fully responsive fluid UI.
